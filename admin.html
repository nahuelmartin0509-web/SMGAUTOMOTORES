Checklist de Firebase

  1. Publicar firestore.rules en Firestore Database → Reglas.
  2. En Authentication → Settings → User actions: desmarcar “Enable create (sign-up)” para que nadie se pueda registrar solo. Crear los usuarios del staff desde la consola.
  3. Rol: si el email contiene admin → Administrador / Dueño; cualquier otro → Vendedor / Gestoría.
  4. costos (costo de toma y venta final) solo lo lee y escribe el Administrador.
  5. catalogo es el espejo público que lee index.html: solo autos Disponibles o Señados, sin datos internos.
